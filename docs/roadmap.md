# Roadmap and current gates

Updated October 1, 2026 from dated working-project dispositions. This is a capability sequence, not a promised release schedule. The old September 14/15 pending-readiness summaries are historical checkpoints.

## Current position

Phase 0 architecture/discovery foundations are complete. Phase 1 is complete only for its September 20/21 **attended, synthetic-only, retained-16-GB scope**; the original heavy workload remains unsupported. Phase 2 preparation is in progress: native-tool smoke, locked dependency-source acquisition and draft protocol/oracle work exist. **No product Core, Tauri/PWA candidate or Phase 2 comparison has executed.**

The September 21 source checkpoint covered 258 Cargo archives and 10,375 extracted regular files with no identity mismatches. Those integrity checks do not establish executable safety. Draft oracle trace coverage is specification progress, not passed behavior. Later retry clarification remains draft and does not freeze the contract.

Current candidate execution still requires fresh host/resource/runtime admission, reconciliation and freeze of protocol/harness/session/persistence rules, executable/native source review, planned mock Core/runner equivalents, containment qualification and registered comparisons. Source-only preparation or offline developer-tool results cannot silently clear those gates. This public page omits host identifiers and operational configuration.

## Capability progression

| Milestone | Intended result | Evidence before promotion |
| --- | --- | --- |
| A — Baseline | Preserved architecture, requirements, discovery and decisions | Source coverage and approved planning changes; no dependency adoption implied |
| B — Scoped readiness | Admit a named host/workload scope | Applicable measurements and security/recovery prerequisites; no blanket readiness claim |
| C — Architecture experiments | Equivalent Tauri/PWA, runtime mock conformance and Core placement | Frozen contracts, exact dependencies, containment; all eligible initial runtimes accounted for before provisional selection |
| D — Authority foundations | Canonical records, identities, grants, budgets, effects, Stop and audit | Denied-action/crash/ambiguous-effect checks and minimal synthetic restore |
| E — Useful personal workspace | Chat, projects/files, simple memory/search, selectable routes and activity | Exact-route quality, production pairing, restart/context and data gates; off-device restore before personal utility |
| F — Optional research and document workflows | Research, faithful documents and tracking | Admitted research/document routes and truthful source-supported results; no submission authority |
| G — Browser workflows | Dedicated-profile observation, fill and separately authorized submission | Synthetic site/account tests, takeover, receipts and no blind ambiguous retry; bounded preparation soak before expansion |
| H — Broader capabilities | Archive import, coding, skills/plugins, image jobs and interactive UX choice | Each capability's data/route/intake/recovery evidence; independent of external submission |
| I — Optional expansion | 100K retrieval/graph, remaining specialists, voice, companion/device capabilities | Measured value/resources and separate platform/enrollment/revocation scopes |
| J — Release and evolution | Signed lifecycle, clean-host recovery, incident handling and controlled updates | Included scope individually admitted, applicable security/recovery/soak evidence and explicit release decision |
