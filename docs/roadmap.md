# Roadmap

Status checked against the working project's ledger on September 14, 2026. This is a sequence of capabilities, not a promised release schedule.

## Established foundations

- A preserved 19-document architecture baseline.
- Requirements traceability, decision records and integration evaluation criteria.
- Planning and evidence templates, inventories and artifact/readiness validation tooling.
- A public architecture explorer showing intended behavior with mock components.

## Current work

Validate the environment and remaining prerequisites for implementation. The working ledger records foundation readiness as pending evidence. The core application build has not started.

## Planned progression

1. **Useful core:** project records, files, settings, activity and durable task state.
2. **Selectable model routes:** local and hosted model adapters, visible selection and usage controls.
3. **Bounded tools and workflows:** typed actions, permissions, cancellation and resumable execution.
4. **Retrieval and memory:** rebuildable indexes with source provenance and user control.
5. **Broader interfaces and integrations:** additional workflows and companion interfaces after their prerequisites are validated.

Each capability needs its own evidence. The presence of a plan, prototype or candidate integration does not mean that the corresponding feature is deployed.
