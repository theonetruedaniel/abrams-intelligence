# Contributing feedback

Abrams Intelligence is a solo architecture and foundations project maintained by Daniel Abrams. This repository contains a curated public overview. Useful contributions at this stage include documentation corrections, source-backed research and specific questions about the design.

## Propose a change

Open an issue describing the problem, the relevant document and your supporting evidence. For a candidate suggestion, include the canonical repository URL, exact source revision, proposed role, useful behavior and a test that could disprove its fit. Separate observed source behavior from a proposed experiment.

For a documentation pull request, explain the change and check relative links and JSON syntax. Preserve the distinction between established design, simulation, proposed testing and implemented behavior. Discuss scope before contributing product code: this showcase has no application build or runtime dependencies.

Use synthetic examples. Omit credentials, personal records, private host details and third-party material you do not have permission to share. Keep feedback respectful and focused on the work.

## Attribution and licensing

Link upstream sources and retain their authorship. A reference does not mean that a project has been adopted. This showcase has no open-source license at present; discuss intended reuse with the maintainer before proposing imported code or substantial reusable contributions.
